# Walk with Jesus

A gentle mobile game for children. Lead people to follow Jesus through Bible and Book of Mormon places.

- Play: https://actionreplayau.github.io/walk-with-jesus/
- On a phone, open the link, then Share → Add to Home Screen to install it like an app. It works offline after the first visit.

Everything is in `index.html`. The pictures are in `art/` and `art2/`.
